## 0.1.0

- Initial release.
- Added annotations for Flutter Layered Architecture conventions:
  - `@usecase` — marks Usecase types
  - `@delegate` — marks Delegate types
  - `@state` / `@entity` — marks state and entity models
  - `@stateful` — marks stateful types that own `MutableStateStream`
  - `@viewModel` — marks ViewModel types
